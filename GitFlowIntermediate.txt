Anwers to the questions in the LAB: 1. One would use the Stash option when you are mid-edit and not ready to commit or push your work. Mid edit you might not yet know if your code works or looks as you want it. Hence put it in Stash when pausing that edit. A temporary branch would still be something that is more or less ready to commit, a branch can be a complete edit and focuses on a specific feature or detail. While Stash is mid-work. 2.[Git reset --hard] this is to be used with caution as this command discards local changes. So unless they are stashed somewhere, honestly I am not sure that it discards all changes even if they are in the Stashed list. But all local changes would include all branches and in the LAB example it is paired with [git push --force] which will rewrite the remote history so that unsaved edits and branches are too edited. Meaning you might delete not only your local repo but also delete your collegues branches and edits. A quick way to make your companions frustrated.
